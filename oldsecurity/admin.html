PLUG-IN GUIDE
After uploading graphics here, to use them in the 50s broadcast:
1. Logos → Reference as ./graphics/50s/logo.png in 50s.html
2. Backgrounds → Set as CSS background-image in 50s.css .tv-screen
3. Weather Icons → Replace emoji in 50s.js wxIcon() with <img src="./graphics/50s/icon-sun.png">
4. Crests → Drop into ./graphics/50s/crests/ and reference in 50s.html header
5. Overlays → Add as positioned <img> tags inside #tvScreen

GRAPHICS FILE GUIDE
Place your graphics in the following folder structure in your repo:

/graphics/50s/logo.png — 50s CWN logo (used as screen watermark)
/graphics/50s/bg-day.jpg — Day mode background
/graphics/50s/bg-night.jpg — Night mode background
/graphics/50s/crests/ — All crest/badge images
/graphics/50s/icons/ — Custom weather icons (PNG with transparent bg)
/audio/music/ — Background music files
/audio/sfx/ — Alert tones and sound effects
/audio/sfx/alert-tone.mp3 — Primary CWN alert tone

To reference in 50s.html: <img src="./graphics/50s/logo.png">
To reference in 50s.css: background-image: url('../graphics/50s/bg-night.jpg');
